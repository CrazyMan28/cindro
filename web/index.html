Setup & Pairing

Pair with a code

In the Jarvis app open Settings → Browser Extension → “Generate pairing code”, then paste the 6-digit code here. Jarvis fills in the control token for you — no hunting through config files.

Or enter the token manually

The control token is in ~/.config/jarvis/control_token on the machine running the daemon. The daemon's control WebSocket is loopback-only.

This dashboard connects your browser directly to the daemon control WebSocket at ws://127.0.0.1:8795/control/ws. That endpoint is loopback-only by design, so the browser must run on the same machine as the daemon. To use it from another device, forward the port first, e.g. ssh -L 8795:127.0.0.1:8795 host or a Tailscale tailscale serve tunnel — then point this page at the forwarded port.
