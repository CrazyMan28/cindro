Computer Use Bridge

Connects to the local computer-use MCP server + the Cindro desktop daemon.

Pair with a code (easy)

In the Cindro app open Settings → Browser Extension → “Generate pairing code”, then paste the code here. Cindro fills in both tokens for you — no hunting through config files.

Or enter tokens manually

The bearer token is in ~/.computer-use/config.yaml on this machine.

Cindro co-worker side panel

The side panel chat connects to the desktop daemon's control WebSocket. Token is in ~/.config/jarvis/control_token on this machine (the desktop daemon's control token).
